# JetBrains Mono Nerd Font licensing and attribution

The four font files are distributed unchanged from Nerd Fonts v3.4.0 under
SIL OFL 1.1. The archive's `OFL.txt` and the Nerd Fonts root `LICENSE` are
retained here. The OFL permits embedding and redistribution with software;
these notices must accompany distributed copies. Runyte does not modify the
fonts. Nerd Fonts applied the icon additions and font-name changes upstream.

Nerd Fonts source: <https://github.com/ryanoasis/nerd-fonts/tree/v3.4.0>.
Base font: <https://github.com/JetBrains/JetBrainsMono> (2.304).
The font file metadata retains the JetBrains copyright and OFL license.
