The syntax folding bindings use `Space x f` to toggle the fold at the cursor,
`Space x F` to fold all syntax regions, and `Space x u` to unfold all syntax
regions.

Folding all regions should use the unshifted mnemonic `Space x f`. Toggling
the fold at the cursor should use the repeated namespace key `Space x x`.
Unfolding all regions should remain on `Space x u`.
